Complete methods API catalog

Every class exported by ccpy.methods.__all__ is included below. Constructors are read from __init__ (including inherited constructors), rather than the generic allocation signature. Defaults are class-level values; instance settings can override them. Base classes are extension protocols, not runnable methods.

For usage and compatible scientific chains, see Ground states and energy corrections, Excitation, attachment, ionization, ADC and STEOM, Initial guesses, symmetry and choosing roots, FNOs, active spaces and selected determinants and Left states, densities, response and gradients. A listed flag or inherited attribute is not a guarantee that every model/reference combination is implemented.
