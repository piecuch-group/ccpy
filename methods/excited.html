Excitation, attachment, ionization, ADC and STEOM

Energy and sector conventions

All EOM methods return target total energies from energy(). omega is the raw eigenvalue relative to the parent determinant’s correlated ground state:

\[\omega = E_{\mathrm{target}}-E_{\mathrm{parent}}.\]

EE and SF preserve electron number; IP/DIP remove one/two electrons and EA/DEA add one/two. Positive IP roots are ionization potentials. The conventional positive electron affinity is -omega for attachment. For FNO-completed energies use completed_omega; see FNOs, active spaces and selected determinants.

A neutral EOM example, starting from native SCF mf:

from ccpy import CCSD, EOMCCSD

cc = CCSD(mf, nfrozen=1)
eom = EOMCCSD(cc)
eom.initial_guess(method="cisd", multiplicity=1, nacto=2, nactu=2,
                  roots_per_irrep={"A": 4}, roots=[0, 2])
totals = eom.energy()
first_returned_total = eom.energy(root=0)
print(eom.omega, eom.root_irreps, eom.root_converged)

EOM raw totals are reference_energy + hbar.correlation_energy + omega. For HBarCCSDTA the HBar owns an augmented correlation energy and new amplitudes, distinct from the original CCSD parent. Consequently completed_omega = energy() - cc.energy() can include that parent-energy change even without FNOs. Use the HBar correlation energy when you specifically want a gap relative to the augmented parent, rather than assuming every omega uses the original CCSD energy zero.

The same method may be constructed directly from mf, nfrozen=1 to create its standard parent automatically. Ordinary EOM requires an explicit initial_guess call. See Initial guesses, symmetry and choosing roots for spin, symmetry and the difference between guess indices and returned-root indices.

Charged EOM catalog

The numeral in IPEOM3 or EAEOM3 describes the largest hole/particle sector in R; it does not automatically change the ground-state parent from CCSD to CCSDT. The explicitly named ...CCSDT variants do change that default.

IP/EA wrappers use the existing alpha-removal/attachment operator branch. For closed-shell parents, spin-equivalent partners need not be solved separately; for open-shell parents this is a specific spin projection, not all possible charged spin sectors. Default charged guesses use multiplicity=-1.

from ccpy import DIPEOM3, DEAEOM3, Molecule, ROHF, SFEOMCCSD

dip = DIPEOM3(cc)
dip.initial_guess(method="dipcis", nacto=cc.system.noccupied_alpha,
                  roots_per_irrep={"A": 2})
dication_totals = dip.energy()
dea = DEAEOM3(cc)
dea.initial_guess(method="deacis", nactu=min(4, cc.system.nunoccupied_alpha),
                  roots_per_irrep={"A": 2})

high_spin = ROHF(Molecule("C 0 0 0; H 0 1 .6; H 0 -1 .6",
                         "6-31g", multiplicity=3))
sf = SFEOMCCSD(high_spin)
sf.initial_guess(method="sfcis", multiplicity=-1, roots_per_irrep={"A": 2})
spin_flipped_totals = sf.energy()

The appropriate parent electron number is part of the physical model: DEA starts from an N-2 parent for an N-electron target, DIP from N+2. Ensure charge, basis diffuseness and parent spin are appropriate before requesting roots.

corrected = CREOMCC23(eom, variant="D")

approximate = EOMCCSDTA(cc)

                          roots_per_irrep={"A": 2})

CREOMCC23.energy() adds ddeltas (the size-intensive correction). full_energy() instead adds deltas, including the non-intensive r0 term. raw_energy() and full_raw_energy() omit FNO completion. Other excited corrections ordinarily add their deltas to their parent EOM totals. There is no universal completed_omega property on correction objects: subtract the chosen, consistently corrected parent ground total explicitly when constructing a corrected gap. Do not subtract an unrelated CCSD total if the desired definition requires a corrected ground state.

ADC(2): full and folded

ADC2, IPADC2 and EAADC2 operate directly on a reference, without a CC solve or HBar. Their guesses use the bare Hamiltonian. RHF, ROHF, UHF and noncanonical occupied/virtual blocks are supported using the documented spin-Fock partition including first-order Fov singles.

from ccpy import ADC2, IPADC2, EAADC2

adc = ADC2(mf, nfrozen=1)  # formulation="folded" by default
adc.initial_guess(method="cis", multiplicity=1,
                  roots_per_irrep={"A": 2})
totals = adc.energy()
density = adc.virtual_density(root=0)

satellites = IPADC2(mf, nfrozen=1, formulation="full")
satellites.initial_guess(method="ipcisd", nacto=2, nactu=2,
                         roots_per_irrep={"A": 4}, roots=[3])
satellite_total = satellites.energy(root=0)

Folded mode stores primary Davidson vectors and reconstructs satellite amplitudes using the diagonal resolvent; its default guesses are CIS/IP-CIS/ EA-CIS. It targets primary-dominated states. Full mode stores the expanded linear eigenvectors and defaults to CISd/IP-CISd/EA-CISd, allowing doubles and satellite targeting. Both use CCpy Davidson and return reconstructed normalized full vectors for virtual state densities. Folded poles, unusable primary seeds, duplicate roots and unconverged solutions raise explicit errors. See Density-fitted ADC(2) for equations, storage, density order and validation.

STEOM: automatic and manual calculations

STEOMCC requires a closed-shell restricted CCSD parent and target multiplicity 1 or 3. It solves charged auxiliaries, constructs a second similarity transformation and then a neutral effective problem. It is not an alias for an EE-EOMCCSD calculation.

from ccpy import STEOMCC, STEOMCCSDT

automatic = STEOMCC(cc, nroots=3, multiplicity=1)
automatic_totals = automatic.energy()
manual = STEOMCC(cc, nroots=3, nacto=2, nactu=3)
manual.initial_guess(method="cisd", nacto=2, nactu=3,
                     roots_per_irrep={"A": 5}, roots=[0, 2, 4])
targeted_totals = manual.energy()
extended = STEOMCCSDT(cc, nroots=3, nacto=2, nactu=3,
                     auxiliary_solver="pspace", minimum_active=1)
extended_totals = extended.energy()

Without explicit active counts or lists, ordinary STEOM chooses CIS natural orbital spaces. occupied_threshold and virtual_threshold control cumulative populations; defaults are 0.99 for singlets and 0.999 for triplets. Alternatively specify both nacto/nactu or both zero-based active_occupied/active_virtual lists. ip_threshold/ea_threshold filter auxiliary singles character (ordinary defaults 0.9 singlet, 0.8 triplet); condition_limit controls model-overlap conditioning.

The neutral guess active space is separate from the charged auxiliary active space. Ordinary STEOM has a singles-only final projection: a CISd guess can select a state but cannot turn it into an SD diagonalization. Use STEOMCC(..., level="sdt") or STEOMCCSDT for the extended SD projection. That class retains a CCSD ground state, enlarged charged satellite models, and optionally higher-rank auxiliary sectors. Its additional controls include auxiliary_order=2|3, auxiliary_solver="pspace"|"dense", minimum_active, ip_pspace, ea_pspace and dense_limit.

Inspect omega, singles_weights, auxiliary model weights, orbital_rotations and convergence diagnostics. The extended implementation is a correctness-oriented research implementation with omitted neutral quadruples and no production-performance claim. Ordinary returned singles are not full property wavefunctions. See Spin-integrated STEOM-CCSD for normalization, spin/solver behavior, active-space definitions and limitations.
