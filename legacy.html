Legacy Driver interface

These pages describe the older Driver and adaptive-driver APIs, including PySCF/external interfaces and run_cc / run_eomcc method strings. For the native object-oriented ccpy.methods interface, its method composition, FNOs and root conventions, start with The methods API: a calculation guide.

The APIs coexist. A legacy Driver state index or option spelling is not necessarily an object-oriented method’s returned-root index or keyword.
