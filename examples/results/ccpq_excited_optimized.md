# Optimized excited-state CC(t;3) / determinant gradient comparison

The matched full calculation is optimized `EOMCCSDT_P` for the P-space
states, followed by `EOMCCP3` for the Q-space correction. The determinant
code independently solves its CC(P), right/left EOM and adjoint equations;
no tensor-code amplitudes or roots are supplied to its solver. Numerical
gradients are finite differences of the optimized tensor energies.

## Definitions

The primary molecule is H2O/6-31G at the same asymmetric geometry used for
the ground-state comparison (angstrom):
`O 0 0 0; H .05 -.75 .59; H -.03 .78 .62`.
The reference is native RHF with DF (`def2-universal-jkfit`). O(1s) is frozen
in correlation; all 13 spatial basis orbitals are retained. The full
determinant support has 245,025 states. P contains all 64 singles, all 1,360
doubles and 2,436 active triples. Q is all 8,764 remaining triples.

The active-triples list is generated by CCpy with one active occupied MO,
one active virtual MO and `num_active=1`: at least one active hole and one
active particle are required. The same underlying P selection is used for
ground T and excited R/L. Actual triples lists are stored in each JSON
report and held fixed across displacements. This test does not compare
different ground and excited P selections.

A nonplanar H4/6-31G control uses
`H 0 0 0; H .12 -.06 1.0; H -.08 .10 2.1; H .15 .06 3.15`.
All four electrons and eight spatial orbitals are retained. Its P contains
24 S, 174 D and 160 T; Q contains all 200 remaining T. The full support has
784 determinants. Both checked states have nonzero Q corrections. The
singlet also has a nonzero reference component, |r0| about 0.083, directly
exercising that part of the excited-state correction and response.

Each molecule targets the lowest triplet and lowest singlet in the fixed
Ms=0 determinant sector. Independent optimized-HR Arnoldi ordering maps
these to determinant states 1/2 in water and 1/3 in H4. This avoids equating
the first singlet with the second root of an unfiltered Ms=0 spectrum.

Variant A uses the bare-Fock/excitation-energy denominator (`mp`); variant D
uses the full diagonal denominator (`full`). All Cartesian components are
checked: nine for water, twelve for H4. The numerical total derivative is
the sum of separately differenced base-state and correction energies. These
are total excited-state energy gradients, including nuclear repulsion in
the base term, rather than derivatives of excitation energies alone.

## Root and integral checks

- Native RHF, CCSDt, right EOMCCSDt and left EOMCCSDt are re-solved at every
  displaced geometry. Tensor iteration tolerances are 1e-13 in energy and
  1e-11 in amplitudes; the reference uses 1e-13/1e-11 RHF tolerances.
- Both multiplicities use complete alpha/beta spin blocks, including all
  allowed triples spin cases, without singlet-only equation shortcuts.
- The native right/left vectors are converted from redundant spin blocks
  to unique determinant coordinates, including operator phases. Physical
  L.R normalization and reference-component conventions are checked.
- An independent SciPy Arnoldi solve uses the optimized HR action in unique
  P coordinates (four lowest roots, `which=SR`, `ncv=32`, tolerance 1e-12).
  Its spectrum is compared with the determinant Davidson buffer. Native
  and determinant right/left eigenvector overlaps are also checked.
- Displaced orbital signs are aligned by cross-geometry AO overlaps. No
  orbital mixing/reordering is used. Displaced native right-vector overlap
  must exceed 0.9 and excitation-energy drift must stay within one quarter
  of the nearest reference-buffer gap. Left/right eigenvalues must agree.
- The determinant analytical calculation uses
  `integral_model="factorized"`, so its Hamiltonian, orbital response and
  DF-vector derivatives differentiate the same fitted integrals as the
  optimized energies. This includes auxiliary/metric derivatives.

The optimized full EOM methods currently reconstruct four-index integrals
from DF vectors; they are independent tensor implementations, not fully
factorized excited-state kernels. The determinant backend uses FCIpy Slater
actions and sparse connected storage, without a dense full-space Hamiltonian.

## H4 finite-difference step convergence

The first singlet lies close to another root (a gap about 0.00228 Eh).
The original 0.001-bohr four-point stencil gives visible truncation error.
Halving the step reduces the correction-gradient error by approximately 16,
consistent with fourth-order finite differences. For atom 0/z, singlet D:

| Step (bohr) | Base error | Correction error | Total error |
|---:|---:|---:|---:|
| 0.001 | 7.155e-8 | 2.486e-8 | 4.669e-8 |
| 0.0005 | 4.473e-9 | 1.559e-9 | 2.915e-9 |
| 0.00025 | 2.684e-10 | 9.716e-11 | 1.713e-10 |

Errors are Eh/bohr. The final H4 demonstration uses 0.00025 bohr for all
twelve components; water uses 0.001 bohr. Neither the analytical equations
nor the 2e-8 Eh/bohr acceptance tolerance was changed to resolve this.

## Which optimized correction is full?

For this comparison, full excited-state CC(t;3) is the specialization of
`EOMCCP3` to the CCSDt active-space T/R lists. It uses selected R3 and L3
contributions in the moments as well as the CCSDT(P) Hbar and left state.

`EOMCCT3(two_body_approx=False)` is also audited at the reference geometry,
but is not substituted for `EOMCCP3`: its flag retains the full Hbar instead
of removing VT3 intermediates, while `calc_eomcct3` still calls correction
kernels using only the SD parts of R and L. Its separate correction values
are recorded under `cct3_flag_false_delta` in the reports. A flag value alone
does not make those SD correction contractions the full CC(P;Q) functional.

## Reproduce

With CCpy's build environment and optional FCIpy connector configured:

```sh
OPENBLAS_NUM_THREADS=1 python examples/ccpq_excited_optimized_comparison.py \
  --molecule h4 --step 0.00025 \
  --output examples/results/h4_631g_excited_optimized.json
OPENBLAS_NUM_THREADS=1 python examples/ccpq_excited_optimized_comparison.py \
  --molecule water \
  --output examples/results/h2o_631g_excited_optimized.json
OPENBLAS_NUM_THREADS=1 python -m pytest tests/gradients/test_ccpq_excited_optimized.py -q
```

Complete results include analytical arrays, optimized numerical components,
energy differences, solver diagnostics, eigenvector overlaps and per-point
root-following checks:

- [H4/6-31G](h4_631g_excited_optimized.json)
- [H2O/6-31G, frozen O(1s)](h2o_631g_excited_optimized.json)

The expanded regression run passed **144 tests** (`tests/gradients` plus
`tests/scf/test_ccpq_gradient.py`), including four fresh optimized-tensor /
determinant excited-state comparisons. Those tests include nonzero Q
corrections, a nonzero singlet r0, root-order verification and both A/D
denominators. The H4 regression uses the step established by the convergence
check above, without relaxing the comparison tolerances.
